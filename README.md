# Stack Sprint — Sky Courier Collection

Version 3.0.0. This repository contains the public browser deployment: `index.html` and `vercel.json`.

## Deploy to the existing Vercel project

- Project: `stack_sprint_vercel`.
- Connected repository: `dinnagaranasinghe-svg/yt-game`.
- Production branch: `main`.
- Framework preset: Other.
- Root Directory: repository root (blank).
- Build and install commands: none.
- Output Directory: `.` (configured in vercel.json).

After connecting the repository, deploy the main branch and retain the existing domain https://stacksprintvercel.vercel.app/ so returning players keep access to their browser saves. The repository is ready to deploy; publication here does not confirm Vercel deployment.

## Updates and saves

Update the built index.html on main to trigger the project's normal Git deployment workflow after it is connected. Standalone progress is browser-local, not linked to an email account. The v3 build migrates earlier supported saves under the existing storage key.

## Release checks

The local build passed its automated gameplay, save, SDK-mock and package checks. Physical-device performance, real-browser acceptance and YouTube certification remain outstanding. Before treating a new deployment as verified, check the Sky Courier Collection title, launch a campaign level, earn progress, reload, confirm saved progress, and test sound/pause and touch controls on a phone.

Editable source, research and QA material are distributed separately and are not part of this public deployment repository.
